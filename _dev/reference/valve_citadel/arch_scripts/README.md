# The Combine architecture study's scripts (21 November)

Written by the study's helper to measure the Combine's structures in the Citadel maps (`../notes/architecture_notes.md`). Kept for the generator the study plans (`_dev/tools/map_combine.py`, not built): `walls.py` has the wall mirror test it would check itself with. They expect the VMFs in the scratch folder (`docs/dev/valve-ingest-progress.md`, "Getting the maps again") and were run with `python3 -I`; not tested as part of the repo's checks.

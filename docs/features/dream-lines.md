# Dream lines to record

Every line said in the dreams you play, made from the code by `python3 _dev/dream_lines.py` (never edit by hand: rerun it).

**How to use a recording:** save it as the file name below (`.mp3`, `.ogg` or `.wav`; a second take can be `...2.mp3`, one is picked at random) in the server's `garrysmod/sound/livingcity/dreams/voice/`. If the words you recorded differ, put them in a `.txt` of the same name (`horse_grigori1.txt`) and those show on screen instead. Then FastDL sync and a map change, as with every new sound. Without a recording, the words still come up at the bottom of the screen.

**Music** for any dream goes in `garrysmod/sound/livingcity/dreams/`, named for the dream's codeword (the word in brackets below): `horse1.mp3`, `boxing1.mp3`. Dance Marathon follows its song's tempo: put the BPM in `dance1.txt` (just the number, like `120`).

**The voices in the dark:** The Cheese Dream uses Half-Life 2's own citizens ("Sometimes I dream about cheese"). Hooves and All uses Half-Life 2's hungry line too, unless you record `horse_intro_male1.mp3` and `horse_intro_female1.mp3`, which take its place. Either way they echo, far off, in the dark.

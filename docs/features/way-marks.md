# The Resistance's way marks (14 November)

The owner, 14 November: "graffiti arrows and such to be used by the editor tool specifically as permanent decals to point the way towards resistance territory ... one should be pointing left, the other decal right, another forward, and another down ... the same orange color as the lambda that is also in the decal, or maybe ... 'Freedom this way'".

`sv_livingcity_waymarks.lua`, the editor `lua/weapons/gmod_tool/stools/livingcity_editor.lua`, painting in `cl_livingcity_war.lua`, tests `WayMarkTests`.

- **Five marks,** sprayed by hand in the lambda's orange, each with the lambda in its ring: an arrow pointing **left**, **right**, **up** (for straight on) and **down**, and the words **FREEDOM THIS WAY** (FREEDOM in white), to go beside an arrow.
- **Painting one:** Miscount Editor, mode "Point: Resistance way mark, pointing left" (or right, up, down) or "Point: Resistance way mark, FREEDOM THIS WAY", then left click a **wall** (not a floor or a ceiling: the game turns floor decals its own way, so an arrow there would not point where you meant). Undo works; right click near one takes it off, as any point. In "Arrange by what it's for" they are under The Resistance and rebel bases.
- **Permanent:** a mark is part of the layout (a `waymark` point: its number is which mark, its yaw the way the wall faces), saved with it and back after every map change. It is sent to players with the sprayed tags and painted the same way, about 107 units across (half as big again as a sprayed tag; `lc_tag_scale` on a player's own game scales it with the rest). It never fades (`lc_tag_minutes` does not apply) and no spray can makes one.
- **Scrubbed off, it comes back** (the owner, 14 November: "allow them to be scrubbed off, but they just reappear a few minutes later when no one is looking"): anyone who can scrub a sprayed tag scrubs a way mark the same way (E on it, 3 seconds), for the same thanks (+3 standing, or a unit's 4 XP; the Resistance won't). It stays off for at least 4 minutes (`LC.WayMarkReturn` 240), then is back as soon as no living player is within 2500 units with a clear line to the wall (`LC.WayMarkSight`, `LC.WayMarkSeen`). The city's own cleaners (sanitation NPCs, stalkers) leave way marks alone. Only the editor removes one for good.
- **Pictures:** `garrysmod/materials/livingcity/graffiti/arrow_left.png`, `arrow_right.png`, `arrow_up.png`, `arrow_down.png`, `freedom.png` (512 x 512, see-through), loose in the server's `garrysmod/` with the other graffiti (`livingcity_content.zip`). Without its picture a mark shows as the game's own lambda spray. They are drawn by `node _dev/posters/arrows.js OUTDIR`.
- **The pictures reach every player, whatever the downloads do** (the owner, 14 November: the marks "all just spray a lambda ... never the proper graffiti texture we implemented"). A player's game painted the lambda whenever it had not the picture, and it had it only when the picture was loose in the server's `garrysmod/materials/livingcity/graffiti/` and the FastDL had been synced since. Now the gamemode carries its own copy of each mark's picture (`gamemodes/livingcity/content/graffiti/`, all seven, 190 KB together, 256 colours) and a game that lacks one asks the server for it (`lc_art`; `LC.SendArt`, in pieces of 30 KB) and keeps it in its own data folder (`data/livingcity/art/<mark>.png`, `LC_CL.ArtPiece`). The owner's loose picture, where there is one, is the one used and sent (`LC.ArtFile`); `lc_art_ver` tells games that kept an older set to ask again. While a picture is on its way (up to 20 seconds) the mark is not painted as a lambda in its place. The same goes for the spray can's tally and NO RECORD, so the can now always offers all three marks. The debug report has a line "mark pictures" saying how many are loose and how many are the gamemode's copies. Tests `Nov14C_MarkArtTests` and the client smoke test.

WHEN: A block raid finishes.
VOICE: The Administrator, tone firm (firm: the kindly parent losing patience)

This folder is her FIRM tone (the usual one for this trigger).

Drop .wav, .mp3 or .ogg files in this folder. One is chosen each time.
